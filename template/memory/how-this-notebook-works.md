Each note holds one fact and says why it matters. The `description` line above
is what shows up in `memory/INDEX.md`, so write it for a future agent deciding
whether this note is worth opening.

When a fact changes, edit this file rather than writing a new one. Git keeps
the history, and the search service keeps every earlier revision out of recall.
